# 文旅部网站分类草案

## 推荐分类法
先不要按页面看到的所有标题直接平铺，而是固定成下面 4 层：

1. `站点`
2. `频道组`
3. `栏目`
4. `子栏目`

这样做的原因：

- 同一个栏目可能在多个导航入口重复出现
- 有些链接是专题页，不是最终文章列表
- 有些栏目还有嵌套，需要继续往下钻
- 后续你继续加别的部委网站时，结构能保持一致

## 文旅部建议分站点

### 1. 主站
- 域名：`www.mct.gov.cn`

  - 互动交流

### 2. 政府信息公开站

## 未解决栏目怎么标

你说得对，有些现在还不是最后一级子网站。  
建议系统里不要强行当终态栏目，而是单独加一个抓取深度字段：

- `terminal_list`：已经是最终列表页
- `nested_hub`：还是中间层，需要继续下钻
- `special_topic`：专题页，结构可能不规则
- `year_archive`：按年份归档

这样你后面继续补数据时，系统不会把“还没解决的嵌套页”误判成最终抓取目标。

## 文章级原网址怎么存

你这个要求非常重要，建议每篇文章至少保留下面这些字段：

- `site_name`：来源站点名
- `site_domain`：来源域名
- `channel_group`：频道组
- `module_name`：栏目名
- `submodule_name`：子栏目名
- `list_url`：文章是从哪个列表页发现的
- `detail_url`：文章最终详情页网址
- `detail_title`：详情页标题
- `breadcrumb`：页面面包屑路径
- `captured_at`：抓取时间

重点是：

- `list_url` 解决“这篇文章来自哪个栏目列表”
- `detail_url` 解决“这篇文章自己的原网页到底是哪一个”

以后详情页里展示原网址，应该优先展示 `detail_url`，不是 `list_url`，更不是部门首页。

## 抓取策略建议

### 已经可以直接抓的
- 时政要闻
- 焦点新闻
- 领导活动
- 工作信息
- 直属单位
- 图片新闻
- 政府信息公开指南
- 政府信息公开制度
- 政府信息公开目录下大多数主题分类页
- 体裁分类页
- 年报归档页
- 公共服务

### 需要继续下钻的
- 党建工作
- 全国联播
- 热点专题
- 专项工作
- 互动交流

### 需要去重或确认的
- 信息发布 > 工作信息：和 `文旅资讯 > 工作信息` 重复
- 信息发布 > 全国联播：和 `文旅资讯 > 全国联播` 重复
- 信息发布 > 直属单位：你现在给的 URL 和工作信息相同，建议后续再核对一次
